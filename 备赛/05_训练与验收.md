# 训练与验收

## 通用能力门槛

| 能力 | 最小通过条件 |
|---|---|
| 工具链 | 换电脑后 30 分钟内完成构建、烧录、自检 |
| ADC | 已知输入下完成零点/增益校准，误差表覆盖至少 5 点 |
| DAC/PWM | 5 点线性与负载测试；输出越限/短路行为明确 |
| 幅频相测量 | 三组频率、三组幅值，报告误差和失效边界 |
| 滤波/放大 | 实测增益、截止、噪声、饱和与稳定性 |
| 功率 | 效率、纹波、温升、负载阶跃、过流/关断均有证据 |
| 通信 | CRC/序号/超时/复位检测；拔线后进入安全态 |
| 长稳 | 核心链路连续 4 小时无复位、锁死或数据中断 |
| 替换 | 主控、线缆或关键模块替换后 30 分钟内恢复 |

## 证据格式

每个结论至少包含：

- 固件提交号和 boot 水印。
- 原理图/接线版本。
- 仪器型号、量程、探头设置、输入条件。
- 原始 CSV/照片路径和汇总表。
- 预先写明的通过阈值，不在看到结果后改标准。
- 未通过项、临时绕过和赛中风险。

## 两次模拟赛的判定

只有同时交付“可测实物 + 可冷启动代码 + 测试表 + 设计报告骨架 + 复现记录”才算完成。任一项依赖原作者现场解释，判为未通过。
