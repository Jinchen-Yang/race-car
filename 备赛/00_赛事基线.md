# 赛事基线（截至 2026-07-17）

## 已确认的官方事实

| 项目 | 内容 |
|---|---|
| 赛事 | 2026 年北京市大学生电子设计竞赛 |
| 主办/承办 | 北京市教委 / 北京邮电大学 |
| 队伍 | 3 人一队，本科组与高职高专组分开 |
| 比赛 | 2026-07-29 08:00 至 2026-08-01 20:00 |
| 测评 | 2026-08-03 至 2026-08-04 |
| 资源 | 场地、仪器、元器件和材料原则上由参赛学校提供 |
| 命题 | 由模拟电子系统设计专题赛专家组统一命题 |
| 晋级 | 北京市赛优秀本科队可获推荐参加专题赛决赛 |
| 初赛平台 | 计划不少于 7 题，其中 1 题指定 TI MSPM0 系列，具体型号不限定 |
| 决赛平台 | MSPM0G3507、MSPM0L1306、MSP-EXP430F5529LP、LAUNCHXL-F280049C 中熟悉一种即可 |

## 当前工程判断

- 现有 MSPM0G3507 与官方平台直接匹配，应作为主控首选，不在赛前更换生态。
- 主攻“模拟信号产生、获取、转换、处理与低压变流”，控制/小车作为第一备选。
- 旧小车工程可复用 CCS 工程经验、调度器、串口遥测和故障处理，不复用赛题状态机与未经验证的硬件假设。
- 截至本文件日期，官方 2026 初赛器材清单和赛题页面仍未发布具体内容；2024/2025 清单只能用于备货范围参考。

## 未确认，禁止写成规则

- 是否允许多 MCU、非 TI 协处理器或视觉板。
- 每题允许的模块、自制比例、供电、尺寸和通信限制。
- 2026 正式仪器及器材清单。
- 学校内部报名、场地、领料和封存流程是否已经完成。
