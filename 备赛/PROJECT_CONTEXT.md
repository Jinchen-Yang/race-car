# 电赛小车项目上下文

> 用途：本文件供本地 Codex、Claude Code、Cursor 等代码代理读取项目背景、赛事约束、硬件架构、采购策略和当前决策。
>
> 项目：电赛小车  
> 目标赛事：2026 年北京市大学生电子设计竞赛  
> 承办单位：北京邮电大学  
> 固定核心 MCU：TI MSPM0G3507  
> 最后整理：2026-07-17

---

## 1. 项目目标

本项目不是只做一辆固定功能小车，而是搭建一套可快速重组的通用电赛平台，覆盖：

- 编码器闭环、巡线、避障、停车、定位
- 二维云台、舵机、步进、直流电机和无刷执行器
- 视觉识别、目标跟踪、单目测量
- 模拟信号采集、ADC/DAC、频率/相位/电压/电流/功率测量
- 音频采集、滤波、输出
- 低压功率变换
- 多控制器协同
- 本地 UI、参数整定、故障管理和现场调试

核心原则：稳定、模块化、易维修、可替换、可复测，不靠临场飞线和玄学。

---

## 2. 赛事背景与当前规则理解

### 2.1 已知信息

- 赛事：2026 年北京市大学生电子设计竞赛
- 承办：北京邮电大学
- 3 人一队
- 竞赛时间：2026-07-29 08:00 至 2026-08-01 20:00
- 测评时间：2026-08-03 至 2026-08-04
- 初赛计划不少于 7 道题
- 至少一道题指定 TI MSPM0 系列处理器
- 当前固定 MSPM0G3507 符合该要求

### 2.2 关于“是否必须全部使用 TI”

目前公开信息只能确认：

- 至少一道题指定 MSPM0 系列
- 没有确认“整个系统所有 MCU 都必须是 TI”
- 没有确认“一套作品只能使用一个 MCU”

因此当前最合理的工程判断是：

- MSPM0G3507 应作为系统主控和任务调度中心
- 底盘、云台可以使用独立控制节点
- 最稳妥版本是这些控制节点也统一使用 MSPM0 系列
- 若正式题面允许，可用其他 MCU 作为协处理器
- 视觉板可作为识别协处理器，但不得绕过主控直接拥有不可控的系统控制权

正式赛题若出现“全部控制必须由 MSPM0 完成”“只允许一块处理器”等措辞，必须立即收敛架构。

## 3. 固定主控

固定使用：

- TI MSPM0G3507

此前口述的“tim3507”统一解释为 MSPM0G3507。

画板必须以实际购买核心板为准，必须拿到：

- 原理图
- 引脚表
- 板框尺寸
- 排针间距
- 安装孔位
- Boot / Reset 逻辑
- 供电方式

不同商家核心板不得假定兼容。Codex 不得猜测引脚。

## 4. 推荐总体架构

```text
                         MSPM0G3507 主控
                  状态机 / 任务调度 / UI / 通信
                              |
               +--------------+--------------+
               |                             |
        底盘控制节点                    云台控制节点
     编码器 / 速度环 / 电机            角度环 / 执行器 / 限位
               |                             |
          电机驱动板                    舵机 / 步进 / 无刷
               |
          巡线 / 距离传感

                         视觉处理板
                 目标坐标 / 置信度 / 状态
```

推荐节点：

- 主控 MCU：1 个 MSPM0G3507
- 底盘控制 MCU：1 个，优先 MSPM0G3507
- 云台控制 MCU：1 个，优先 MSPM0G3507
- 视觉板：1 个 MaixCAM 或题目允许的平台
- 无线协处理器：0 至 1 个

### 分布式控制的原因

- 底盘闭环不受屏幕、视觉和日志干扰
- 云台可独立运行高频闭环
- PID 参数互不影响
- 单节点可独立测试和替换
- 软件职责清楚
- 赛题切换时只更换下层节点或子板

建议周期：

- 主状态机：20~100 Hz
- 底盘速度环：500 Hz~1 kHz
- 编码器采样：1 kHz 以上
- 云台角度/速度环：500 Hz~1 kHz
- 视觉更新：20~60 Hz
- UI 刷新：5~20 Hz

## 5. 当前备赛路线

### 主攻

综合测控与仪器：

```text
模拟输入 -> 保护 -> 衰减/放大/偏置 -> ADC -> DMA -> 数字处理
        -> 显示/通信 -> DAC/PWM/执行器输出
```

重点训练：

- 电压、电流、功率、频率、相位测量
- 波形采集、FFT、调制度、失真
- 有源滤波、微弱信号放大
- DAC 输出和闭环给定
- 低压 Buck、Boost、电子负载、恒流

### 第一备选

闭环控制与机电：

- 小车
- 自动泊车
- 巡线和避障
- 磁悬浮
- 二维云台
- 舵机、步进、电磁铁机构
- 棋盘、抓取、分类

### 条件备选

正式器材清单或题面命中后再提高优先级：

- 视觉
- 无线
- UWB
- 雷达
- 无人机
- 工频功率
- 高压逆变

### 不主动选择

除非已有成熟硬件、人员和安全条件：

- 从零搭无人机
- 从零做工频高压全桥
- 临时自研复杂 FOC
- 临时做 UWB 定位

## 6. 主拓展板 RevA

### 6.1 定位

RevA 是通用测控母板，不是纯小车板。

主板负责：

- MSPM0G3507 核心板插接
- 数字和模拟电源分配
- ADC/DAC、比较器、PWM、编码器
- UART、SPI、I2C、CAN-FD
- 屏幕、按键、旋钮、蜂鸣器
- 测试点、保护链和子板接口

主板不负责：

- 大电流 H 桥
- 高压半桥/全桥
- 三相无刷功率级
- 大功率音频功放
- 工频高压采样
- 大功率舵机供电

这些全部独立成子板。

### 6.2 PCB

建议：

- 约 100 mm × 100 mm
- 4 层
- L1：器件与高速信号
- L2：完整 GND
- L3：电源与低速信号
- L4：信号

要求：

- 不随意切割地平面
- 模拟区域远离开关节点
- ADC、基准源远离电机、电感和高 di/dt 回路
- BNC/SMA 靠板边
- 关键点全部有测试点和丝印

---

## 7. 电源架构

建议电源域：

- 主直流母线：7~24 V
- 电机动力母线
- 5 V 数字/视觉
- 3.3 V 逻辑
- 6 V 舵机
- 外部 ±12 V 或 ±15 V 模拟电源
- 可选隔离电源

原则：

- 舵机堵转电流不穿主控板
- 电机回流不穿模拟区域
- 视觉板独立 5 V 支路
- 逻辑和视觉可分别断电重启
- 高压和工频不进入通用主板
- 功率支路必须有保险或电子保护
- 上电时电机、舵机、激光、功率级默认关闭

---

## 8. 主板接口建议

### 模拟输入

至少：

- 4 路通用模拟输入
- 2 路电压同步采样
- 2 路电流同步采样
- 4 路比较器输入

通用输入建议支持：

- 50 Ω / 1 MΩ
- AC / DC 耦合
- 1:1 / 1:10 衰减
- 1 / 2 / 5 / 10 倍增益
- 可调偏置
- 可更换 RC 滤波
- 输入钳位和限流
- BNC 或 SMA

### 模拟输出

- 片上 DAC 缓冲输出 1 路
- 外置双通道 DAC 2 路
- PWM 低通输出 2 路
- DDS 接口 1 路
- 输出限流、短路保护

### 电机

4 路控制口，每路：

- PWM
- DIR
- EN
- ISENSE
- FAULT

### 编码器

4 路 ABZ：

- VCC
- GND
- A
- B
- Z

要求 3.3/5 V 可选、施密特整形、串阻和钳位。

### 舵机

- 8 路
- 两组独立 6 V 供电
- 每组 4 路
- 每组独立保险

### 通信

- UART ×4
- SPI ×2
- I2C ×2
- CAN-FD ×1
- SWD ×1
- 调试 UART ×1

推荐逻辑分配：

- UART0：日志
- UART1：视觉
- UART2：无线
- UART3：题型外设
- SPI0：高速 ADC/DAC
- SPI1：显示、IMU、扩展
- I2C0：板上传感器
- I2C1：外部传感器

## 9. 子板体系

建议准备：

1. 模拟前端子板：放大、衰减、偏置、滤波、保护
2. 精密采集子板：ADS8860 / ADS8681
3. 精密输出子板：DAC80502
4. 功率测量子板：INA240 + 分流器 + 比较器
5. 低压功率子板：UCC27211 + MOSFET
6. 电机驱动子板：DRV8874
7. 音频前端子板：麦克风、低噪放大、原始/包络输出
8. 视觉接口板：独立 5 V、UART/SPI、Reset、状态
9. 传感接口板：霍尔、光电、ToF、AS5600

高压功率板必须独立，并使用隔离和硬件急停。

## 13. 固件分层

```text
Application
  状态机 / 任务逻辑 / 赛题流程

Services
  运动控制 / 云台 / 视觉 / 参数 / 故障 / UI

Drivers
  ADC / DAC / PWM / QEI / UART / SPI / I2C / CAN

HAL
  MSPM0 SDK / 芯片外设封装

BSP
  板级引脚、时钟、硬件版本
```

禁止：

- 业务逻辑直接操作寄存器
- 中断中 printf
- 屏幕刷新阻塞控制环
- 无超时 UART
- 引脚硬编码
- 参数散落为魔法数字
- 上电直接启动电机、激光或功率级

## 15. 控制建议

### 底盘

优先两轮差速或四轮差速，不优先麦克纳姆轮。

```text
路径/位置 -> 线速度和角速度 -> 左右轮目标 -> 速度 PID -> PWM
```

必须支持：

- 编码器方向校验
- 电机极性校验
- 左右轮增益修正
- 加速度限制
- 急停
- 失联刹车
- 堵转检测
- 电池低压限功率

### 云台

```text
视觉误差 -> 目标角度 -> 角度环 -> 速度目标 -> 速度环 -> 执行器
```

普通 PWM 舵机内部已有闭环，外部主要做角度修正；步进或无刷云台才适合更完整的位置/速度双环。

必须有：

- 机械限位
- 零位
- 加速度限制
- 失联回中或安全停机

## 16. 安全

- 激光默认关闭
- 功率级默认关闭
- 急停必须为硬件链
- MCU 死机时执行器进入安全状态
- 高压使用隔离变压器
- 示波器地夹禁止接浮动高边
- LiPo 使用平衡充电和防火袋
- 鼓包电池立即停用
- 无刷桨调试使用保护架
- 机构注意夹伤
- 满载必须检查温升

## 23. 当前推荐最终架构

```text
                        MSPM0G3507 主控
              比赛流程 / 调度 / UI / 故障管理
                           /      \
                          /        \
               CAN/UART/SPI      UART/SPI
                    /                \
         MSPM0G3507 底盘节点          视觉板
      编码器 / 速度环 / 电机驱动     识别 / 测量 / 坐标
                    \
                     \
              MSPM0G3507 云台节点
          角度反馈 / 舵机 / 步进 / 无刷
```

若正式规则允许非 TI 协处理器，可替换底盘或云台节点，但 MSPM0G3507 保持主控，所有节点必须能被主控急停和复位。

若正式规则要求所有控制均由 MSPM0 完成，则所有控制节点统一 MSPM0，视觉板只输出识别结果，不直接控制执行器。
