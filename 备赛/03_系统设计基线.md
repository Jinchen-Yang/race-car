# 系统设计基线

## 主攻：模块化综合测控

```text
输入端子
  -> 限流/钳位/保险
  -> 可切换 AC/DC 耦合、衰减、增益、偏置
  -> 模拟滤波/比较
  -> ADC + DMA
  -> MSPM0G3507：校准、测量、状态机、故障管理
  -> 显示/串口证据 + DAC/PWM/功率级输出
```

模块边界固定，具体器件随正式题目替换：

- 输入保护与量程板。
- 通用放大/滤波板。
- 精密 ADC/DAC 板。
- 电压、电流、功率测量板。
- 低压半桥/Buck/恒流板。
- 人机与调试板。

## 第一备选：闭环控制

旧小车只作为成熟执行平台，不继续扩展大一统架构。新题若命中控制类，复用：

- MSPM0G3507 工程与 SysConfig 经验。
- `scheduler`、`pid`、串口遥测与日志工具。
- 已验证的电机、灰度、IMU 或云台模块中与题面允许项一致的部分。

不得直接复用旧 `app.c` 的赛道状态机、旧参数或旧引脚假设。

## 设计冻结规则

- 正式清单前只冻结接口、电源域、安全默认值和测试点，不冻结题型。
- 模拟与数字电源分支可控，功率回流不穿模拟地敏感区。
- ADC 基准、输入保护、量程、采样率和抗混叠必须成套设计。
- 所有输出上电关闭；看门狗、失联、越限和过流均进入明确安全态。
- 每块板至少准备一个可替换方案；替换后运行同一验收脚本/表格。
